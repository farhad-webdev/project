# Telegram Project Groups

Premium, well-organized directory of Farhad's Telegram project groups, built from the Google Sheet "Telegram Project Groups - A to Z".

- 75 project groups, all WordPress
- Search by client name or niche (peptide, skincare, etc.)
- Filters: link status, year, sort
- Data snapshot: 5 November 2026 — update the sheet, then rebuild to refresh.
